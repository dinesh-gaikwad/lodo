# Ludo Multiplayer Game Rules

## Objective

Move all four tokens from home to the finish area before opponents.

---

# Players

- Minimum Players: 2
- Maximum Players: 4

Colors:
- Red
- Blue
- Green
- Yellow

---

# Starting Rules

1. Each player rolls dice.
2. Highest dice starts first.
3. Rolling 6 unlocks token.

---

# Token Movement

- Dice values: 1 to 6
- Token moves clockwise
- Exact value needed to finish

---

# Safe Zones

Safe zones protect tokens from attacks.

Safe areas:
- Star cells
- Home path

---

# Kill Rules

- Landing on opponent token sends it home.
- Player receives bonus turn.

---

# Bonus Turns

Player gets another turn when:
- Rolling 6
- Killing opponent token

---

# Winning Rules

Winner:
- First player to bring all tokens home.

---

# Multiplayer Rules

- Players join room
- Match starts after enough players
- Real time synchronization using WebSocket

---

# AI Bot Rules

Bot:
- Rolls automatically
- Uses random strategy
- Moves nearest token

---

# Fair Play

- Auto Scripts
- Exploits

Accounts may be banned.
